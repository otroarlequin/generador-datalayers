# Datos compartidos

Carpeta opcional para versionar entregables y backups entre colaboradores.

| Subcarpeta | Contenido |
|------------|-----------|
| `backups/` | Archivos JSON exportados desde **Guías → Exportar backup JSON** |
| `exports/` | Guías exportadas en Markdown, HTML o copias de entrega al cliente |

Estos archivos no se generan automáticamente; el equipo los coloca aquí cuando desea compartirlos vía Git.
